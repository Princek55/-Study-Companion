Student Productivity Companion — a gamified productivity dashboard that helps students manage assignments, deadlines, and study time without it feeling like a chore.

Core features:

Task Planner with priorities, deadlines, subjects, and status tracking
Pomodoro focus timer (25/5/15 min modes) that logs study sessions
Calendar view with 7-day and 24-hour deadline reminders
Gamification system — XP, levels, coins, and daily streaks earned by completing tasks and focus sessions
Reward store to spend coins on unlockable themes and stickers
Achievement badges for milestones like task streaks and level-ups
Profile & analytics — weekly charts for tasks completed, focus time, and subject breakdown

Built as plain HTML, CSS, and vanilla JavaScript (no framework), backed by Supabase for auth, database, and row-level security — so every user's data is private and isolated. Available both as a multi-page site and as a single self-contained HTML file, with a dark "night sky" visual theme (violet, gold, midnight tones) styled around an XP-ring dashboard rather than a generic stat-card layout.
